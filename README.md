# ⏱️ Fines Timer

Минималистичный и лёгкий спидран-таймер без фона поверх любых игр и полноэкранных окон для Windows. Написан на **AutoHotkey v1.1** с использованием **HTML/CSS**.

## ✨ Особенности
* **Полностью прозрачный фон:** никаких рамок и лишних окон — поверх игры отображаются только чёткие цифры с миллисекундами (`00:00.00`).
* **Свободное перетаскивание:** просто зажми ЛКМ по цифрам и перетяни таймер в любое удобное место на экране.
* **Умная индикация состояния:**
  * **Белый** — готов к старту (`00:00.00`).
  * **Неоново-голубой** — идёт отсчёт времени.
  * **Жёлтый** — таймер на паузе.
* **Минимальная нагрузка:** практически не потребляет оперативную память и не влияет на FPS в играх.

## 🎮 Горячие клавиши
* **`F4`** — Старт / Пауза отсчёта.
* **`F5`** — Полный сброс на `00:00.00`.

## 🚀 Как запустить
1. Скачай готовый файл `Fines Timer.exe` из раздела **Releases** справа и запусти его.
2. Или запусти исходный код `Fines Timer.ahk` с помощью установленного [AutoHotkey v1.1](https://autohotkey.com).
3. Чтобы остановить программу, надо будет открыть Диспечер Задач или закрыть её через Tray.
